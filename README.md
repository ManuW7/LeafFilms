# LeafFilms

LeafFilms is a microservice movie application with a React frontend, .NET backend services, PostgreSQL databases per service, Redis read models/cache, RabbitMQ events, and an Nginx API Gateway.

## Quick Start

Requirements:

- Docker Desktop or Docker Engine with Docker Compose v2
- Git

Create local environment variables:

```bash
cp .env.example .env
```

For local development the example values are enough, but for any shared environment replace all secrets in `.env`.

Start the whole system:

```bash
docker compose up --build
```

Open:

- Frontend and API Gateway: http://localhost
- RabbitMQ management UI: http://localhost:15672
- Gateway ping: http://localhost/api/ping

The Nginx image builds the React frontend during `docker compose up --build`, so a separate frontend build step is not required on a clean machine.

## API Documentation

Swagger is generated by each .NET service and routed through Nginx:

- UserService: http://localhost/api/swagger/users/index.html
- CatalogueService: http://localhost/api/swagger/catalogue/index.html
- ReviewService: http://localhost/api/swagger/reviews/index.html
- SocialService: http://localhost/api/swagger/social/index.html
- ActivityService: http://localhost/api/swagger/activity/index.html
- FeedService: http://localhost/api/swagger/feed/index.html

## Health Checks

Each service exposes `/health`. Through the gateway:

- http://localhost/api/health/users
- http://localhost/api/health/catalogue
- http://localhost/api/health/reviews
- http://localhost/api/health/social
- http://localhost/api/health/activity
- http://localhost/api/health/feed

## Authentication

Register and login through UserService:

```http
POST /api/users/register
POST /api/users/login
```

`/api/users/login` returns a JWT token. Protected endpoints expect:

```http
Authorization: Bearer <token>
```

Admin access is role-based. To promote an existing user:

```http
POST /api/users/admin/promote
Content-Type: application/json

{
  "email": "user@example.com",
  "adminSecret": "<ADMIN_SETUP_SECRET from .env>"
}
```

## Development Checks

Backend:

```bash
cd backend
dotnet build LeafFilms.slnx
```

Frontend:

```bash
cd frontend/leaf-films
npm ci
npm run lint
npm run build
```

Compose config:

```bash
docker compose config --quiet
```
